## ✅ STEP-BY-STEP WORKFLOW FOR TEAM

### **Feature Development (Example: Add Shopping Cart)**

1. **Create Feature Branch** (Use GIT_WORKFLOW.md)
   ```bash
   git checkout develop
   git pull origin develop
   git checkout -b feature/456-shopping-cart
   ```

2. **Code the Feature** (3-5 days)
   ```bash
   # Edit files: lib/screens/cart_screen.dart, etc.
   # Commit daily:
   git commit -m "feat(cart): implement cart UI

   - Added cart list view
   - Added price calculation
   - Added quantity controls
   
   Closes #456"
   ```

3. **Open Pull Request** (Use CODE_REVIEW_PROCESS.md)
   - Go to GitHub
   - Use PR template (auto-populated)
   - Request 2 reviewers
   - Pass automatic checks

4. **Code Review** (Use CODE_REVIEW_PROCESS.md Checklist)
   - Reviewers check code quality
   - May request changes
   - Address feedback and push
   - Get approvals

5. **Merge to Develop**
   - Click "Merge pull request"
   - Delete feature branch
   - Update changelog

6. **Presentation Demo** (Use DEMO_SCRIPT.md)
   - Feature is demoed in Week 4
   - Following DEMO_SCRIPT.md segment 3
