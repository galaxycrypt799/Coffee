# Coffee App

Ứng dụng khách hàng cho hệ thống coffee:

- đăng ký và đăng nhập
- xem menu đồ uống
- thêm giỏ hàng và đặt đơn
- theo dõi lịch sử đơn

## Chạy app

```powershell
flutter pub get
flutter run
```
